# 💰 Finance Tracker — Product Case Study

**Role:** Product Manager
**Product:** Finance Tracker (Web Application)
**Status:** Live · Version 1.0
**Launch Date:** April 2026

---

## 📌 Overview

Finance Tracker is a personal finance web application designed to solve a key problem:

> Most tools mix expenses and savings — making it hard for users to understand actual financial progress.

### ✅ Solution

Finance Tracker separates:

* **Expenses** (money going out)
* **Savings/Investments** (money growing)

This gives users a **clear picture of financial health and goal progress**.

---

---

## 🎯 Problem Statement

| Problem                                            | Why It Matters                       |
| -------------------------------------------------- | ------------------------------------ |
| Users can’t clearly distinguish spending vs saving | Leads to poor financial decisions    |
| Existing tools mix financial flows                 | Creates confusion about real savings |

---

## 👥 Target Users

* **Young professionals** managing monthly budgets
* **Students** learning financial discipline
* **Families** planning savings goals

---

## 🧩 Core Features (v1.0)

* Expense tracking
* Savings / investment tracking
* Goal setting with progress bar
* Data visualization (charts)
* CSV export for financial records

## ❤️ Key Insights

### What Worked

* CSV export → high engagement (62%)
* Clear separation of expenses vs savings → strong positive feedback

### What Didn’t Work

* Low goal adoption (8%) → visibility issue

---

## 🔍 Product Decisions

### Problem: Low Goal Usage

**Hypothesis:** Users don’t see the goal feature clearly

**Decision:**

* Move goal section to top
* Improve UI visibility
